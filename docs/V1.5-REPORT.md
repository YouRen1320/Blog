## 关键决策

### 1. 图床本地存储,不上 R2/S3

- 单人博客图片量小(估每月几十张 + 每张 1-2 MB,一年 ~500 MB)
- ECS 40GB 系统盘装得下,Caddy 反代直接出文件,**不需要 CDN**
- 不引入 Cloudflare / AWS 账号
- 切 R2 时改 multer storage 即可,代码层抽象到位

### 2. 图片不放 admin 子域,放 web 子域

`/uploads/*` 走 `www.iyouren.top` 而不是 `admin.iyouren.top`,因为:
- web 端文章页(公开)要直接 `<img src="/uploads/...">`,**主流量都在 web 子域**
- admin 跨子域显示只用 `resolveCoverUrl()` 拼绝对 URL 即可

### 3. Whisper 解耦 LLM_PROVIDER

MiMo / Anthropic / Gemini 都没原生 audio API。`WHISPER_API_KEY` 单独配一个 OpenAI key
(或 dashscope paraformer 走 OpenAI 协议端点),代价是用户多配一个 key。

不用本地 whisper.cpp 是因为 ECS 2GB 内存装不下 whisper-base(~150 MB) + 现有 ai-service 同时跑。

### 4. 录音用 record package(不是 flutter_sound)

record 跨平台 API 简单 + 维护活跃。flutter_sound 功能更全但 API 复杂,小博客不需要。

录音 m4a aacLc @ 16kHz —— Whisper API 推荐输入。文件小,~10s 录音 ~200KB。

### 5. OpenAPI 默认开,不分环境

- 生产开 doc UI 风险:不大,所有 endpoint 已经有 JWT + Roles 守护
- ENABLE_SWAGGER=false 想关随时关
- 单人博客的"内部文档"也能从生产 docs UI 直接看,省一份本地 dev 文档

### 6. AI 审核**只给建议不自动 approve**

LLM 不是 100% 可靠,自动 approve 容易引入低质评论。给 score 让 ADMIN 看一眼快速判,
比每条都自己读完作判断快 5×。建议色(approve 绿 / reject 红)再快 1×。

## 踩坑

1. **Tailwind 不在,但 OTel SDK 装完 Prisma client 又坏一次**:V1.4 装 OTel 已经踩过,这次没再发(node_modules 路径稳定)
2. **`Buffer` 不能直接喂 `new Blob([...])`**:Node 22 lib.dom 类型签名不接 Buffer,需 `new Uint8Array(buffer)` 转一下
3. **YAML mac 资源叉**(`._foo`)在服务器解压后 git 看到 untracked,需要 `find . -name "._*" -delete`
4. **服务器磁盘 94% 满了**:V1.4 build 累积 docker layer + 4GB swap + node_modules 缓存,需要 `docker system prune -af` 清理
5. **服务器 SSH 多 hung 进程吃 MaxStartups slot**:并发 SSH 命令会卡 banner exchange,kill -9 清理后重连
