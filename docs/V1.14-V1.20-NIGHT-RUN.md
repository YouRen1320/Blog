## 局部网络故障详情

`netstat -nr` 在凌晨 02:55 左右显示:
```
47.97.17.43        172.20.10.1        UGHS                  en0
```

`172.20.10.1` 是 iPhone 共享网络的网关 —— 早些时候某次切换 WiFi 时残留。
`route get 47.97.17.43` 也证实流量被强制路由到这个已断开的网关。

`ssh -4` / `ssh -o BindAddress=...` 都不绕开静态路由。
`sudo route delete` 需要密码,无人值守跑不动。
